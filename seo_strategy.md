# SEO Strategy

## In scope
- Public web landing page served by `artifacts/airbnb-manager/server/serve.js` at `/`
- Crawlability and social-sharing assets for the public deployment (`robots.txt`, `sitemap.xml`, canonical tags, Open Graph/Twitter metadata)

## Out of scope
- Native Expo app screens and deep-linked manager routes
- Local-first dashboard, booking, guest, calendar, analytics, and messaging views
- `artifacts/mockup-sandbox/**`
- Express API endpoints that are not public marketing pages

## Target audience
- Airbnb and short-term rental hosts evaluating a property management app

## Primary keywords
- Airbnb property manager app
- short-term rental host management app
- vacation rental host dashboard

## Notes
- The current public SEO surface is a single landing/preview page that tells visitors how to open the Expo app in Expo Go.
- The deployed web experience is not a multi-page marketing site today, so homepage quality and discovery infrastructure carry most of the SEO impact.
